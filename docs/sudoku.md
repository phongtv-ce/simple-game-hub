# Sudoku

9×9 number puzzle with four difficulty levels, pencil notes, undo, hints, and mistake tracking.

**Route:** `/sudoku`

## Getting started

From the repo root:

```bash
pnpm install
pnpm dev
```

Then open `/sudoku` in the app.

## Rules

1. Fill the grid so every row, column, and 3×3 box contains the digits **1–9** exactly once.
2. Cells given at the start (darker text) cannot be changed.
3. Conflicting values in the same row, column, or box are highlighted in red.
4. The puzzle is solved when all 81 cells are filled correctly.

## Controls

| Input | Action |
|-------|--------|
| **Click a cell** | Select it |
| **1–9** | Enter the digit in the selected cell |
| **Arrow keys** | Move selection |
| **Backspace / Delete / 0** | Clear the selected cell |
| **N** | Toggle note mode |
| **Number pad (on screen)** | Tap a digit to fill the selected cell; shows remaining count per digit |

## Features

| Feature | Description |
|---------|-------------|
| **Notes** | In note mode, tap digits to add/remove small pencil marks |
| **Erase** | Clear the selected cell |
| **Undo** | Step back through the last 100 moves |
| **Hint** | Reveal one correct cell at random |
| **New game** | Generate a fresh puzzle at the current difficulty |
| **Timer & mistakes** | Tracks elapsed time and wrong entries |

## Difficulties

| Level | Starting clues |
|-------|----------------|
| Easy | 45 |
| Medium | 36 |
| Hard | 30 |
| Expert | 26 |

Puzzles are generated by building a full valid grid, then removing cells while keeping a unique solution.

## How it works

- `generatePuzzle` fills a complete board via backtracking, then removes cells to the clue count for the chosen difficulty.
- `findConflicts` marks cells that break row/column/box rules.
- `SudokuPage` manages selection, note mode, history snapshots for undo, and keyboard input.
- Given cells are locked; wrong entries increment the mistake counter but do not block play.
